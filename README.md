# 📺 YOUTUBE BLOG | MERN Stack Project

A simple and clean blog posting platform inspired by a YouTube-like UI where users can read published blogs.  
(Upcoming features include user authentication, CRUD operations, likes, and more!)

---

## 🚀 Tech Stack

| Category | Technologies |
|---------|--------------|
| **Frontend** | EJS, HTML5, CSS3, Bootstrap |
| **Backend** | Node.js, Express.js |
| **Database** | MongoDB + Mongoose |
| **Others** | Dotenv, Nodemon, Body-parser |

---

## ✨ Features

✔ Home page displaying all blogs  
✔ Add new blog posts  
✔ Show full blog details  
✔ Delete blogs  
✔ MVC Folder Structure  
✔ Fully responsive + clean UI  

> More features planned soon: User Login, Comments, Blog Images, Dashboard, etc.

## ⚙️ Installation & Setup

### 1️⃣ Clone Repo
git clone https://github.com/Akshatsrivastava26/YOUTUBE-BLOG.git
cd YOUTUBE-BLOG

### 2️⃣ Install Dependencies
npm install

### 3️⃣ Create `.env` file in root
MONGODB_URI=YOUR_MONGODB_CONNECTION_STRING

PORT=5000

### 4️⃣ Run Project
npm start

Then open 👇  
📌 http://localhost:5000/
